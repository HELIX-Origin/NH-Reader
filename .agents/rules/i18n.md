# Rule: i18n

**Status:** CONDITIONAL
**Triggers:** adding or changing any user-visible string, anything under
`src/lib/i18n/**`
**Enforced by:** `npm run i18n:check`

## Must

- **No user-visible string literals in components.** Every label, button, heading, empty
  state, error message, and tooltip comes from the i18n packs.
- **Drop-in packs with `en.json` default:** English is provided by default in `en.json`.
  Community contributors can drop in additional language packs without editing multiple files.
  Any community pack must match the keys in `en.json`.
- **Keys are namespaced by surface**, following the existing shape in `en.json`. Match
  the surrounding convention; do not invent a second scheme.
- **`en` is the source of truth** for key names. `en.json` must read as natural English.
- **Interpolate, do not concatenate** — use the pack's placeholder syntax so word order
  can change per language.
- Locale resolution and the system-locale default live in `src/lib/i18n/index.ts` and
  `src/lib/stores/locale.svelte.ts`. Change behaviour there, not per-component.

## Never

- Never a hardcoded English string in a `.svelte` file or a Rust error surfaced to the
  user.
- Never add a key to a non-`en` pack that does not exist in `en.json`.
- Never reorder or reformat the JSON wholesale — keep diffs to the keys you touched.

## Verify

Any string change runs `npm run i18n:check` **and** `npm run check`.
