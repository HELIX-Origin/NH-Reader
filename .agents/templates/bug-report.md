# Bug report

```markdown
## Summary

One sentence. What is broken?

## Steps to reproduce

1.
2.
3.

## Expected

What should happen.

## Actual

What happens instead. Include the exact error text.

## Environment

- NH Desktop version:
- OS and version:
- Locale:
- Account state: signed in / signed out
- Blacklist: on / off

## Diagnostics

Anything from the app log, or the Rust panic/err output, with secrets removed.

## Notes

When it started, whether it is reproducible every time, and what you have already tried.
```

## Rules

- A report without reproduction steps is a rumour, not a bug. Note it as such.
- **Redact the API key** and any personal paths from diagnostics.
- Prefer one bug per report.
